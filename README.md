# Compound Growth & DCA Calculator

A single-page calculator for visualizing how a starting balance plus regular
monthly contributions compounds over time.

## Features

- Adjustable initial investment, monthly contribution, expected annual
  return, time horizon, and compounding frequency (monthly or annually)
- Live chart of contributions vs. investment growth, with hover tooltips
- Year-by-year breakdown table
- Light/dark theme toggle

## Usage

No build step or dependencies — just open [`index.html`](index.html) in a
browser.

> All figures are illustrative estimates based on a constant annual return —
> not investment advice.
